## Overview

Ping Pong Match Manager is a React-based web application designed to help you organize and manage table tennis tournaments. Whether you're hosting a casual game night or a competitive tournament, this app has got you covered!

## Features

- **Tournament Modes**: Choose between single, duo, or round-robin formats.
- **Dynamic Bracket Generation**: Automatically generates tournament brackets based on the number of participants.
- **Score Management**: Enter and edit scores for each match, with step-by-step navigation.
- **Overview and Diagrams**: View an overview of all matches and scores.
- **Internationalization**: Supports English and Swedish languages based on the user's browser settings.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Wolfskii/Ping-Pong-Match-Manager.git
   cd Ping-Pong-Match-Manager
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

## Deployment

The app is automatically deployed to GitHub Pages whenever changes are pushed to the `prod` branch. The deployment process is handled by GitHub Actions.
